# 커밋 메시지

로컬에서 아래를 한 번 실행하면, `git commit` 시 `.gitmessage` 가 자동으로 열립니다.

```bash
git config commit.template .gitmessage
```

## 형식

```
type: 한 줄 제목 (명령형, ~50자)

본문은 선택. 무엇을·왜 바꿨는지, 주의할 점.

Closes #이슈번호
```

## 타입

| type | 쓰는 때 |
|------|---------|
| `feat` | 새로운 동작·화면·플로우 |
| `fix` | 잘못된 동작 교정 |
| `design` | 스프라이트·씬·폰트·UI 레이아웃 등 **보이는 것** |
| `refactor` | 겉 동작 그대로, 코드·구조만 |
| `perf` | 렌더링·로직 속도 |
| `chore` | 빌드, 설정, 도구, 잡무 |
| `docs` | 문서만 |
| `test` | 테스트 코드 |

## 예시

```
feat: 게임오버 시 즉시 재시작 버튼 포커스

fix: 오프라인에서 랭킹 로딩 스피너가 사라지지 않던 문제

design: 메인 패널 배경 일러스트 교체

chore: 이슈·PR 템플릿 문구 정리

Closes #7
```
