# 커밋 메시지 규칙

실제 편집은 루트의 **`.gitmessage`** 를 사용하고, 여기서는 타입과 예시만 정리합니다.

## 타입 (type)

| type | 설명 |
|------|------|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `design` | UI·스프라이트·씬·폰트 등 비주얼 |
| `refactor` | 동작 변경 없이 구조 개선 |
| `perf` | 성능 개선 |
| `chore` | 설정, 빌드 스크립트, 잡무 |
| `docs` | 문서만 변경 |
| `test` | 테스트 추가·수정 |

## 예시

```
feat: 인게임 일시정지 버튼 추가

fix: 오프라인일 때 랭킹 로딩이 끝나지 않는 현상 수정

design: 메인 패널 배경 에셋 교체

chore: GitHub 이슈·PR 템플릿 추가

Closes #12
```

한 줄 제목은 **약 50자 이내**, 명령형(동사로 시작)을 권장합니다.
